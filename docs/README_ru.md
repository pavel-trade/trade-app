# TW Карта рынка

Один индикатор TradingView (Pine Script v6) на графике цены, который собирает инструменты ручного
волнового анализа Эллиотта: слепую зону, ZigZag, ручную разметку с проверкой правил, последний
импульс и коррекцию A→B→C, каналы, Anchored VWAP, профиль объёма, правило 100–140, риск
и чек-лист «Зона → Истощение → Триггер».

Методика: tradewaves.ru, Б. Вильямс, pr0 / RSWA.

**Это подсказка для анализа, а не торговая система.** Индикатор ничего не обещает и не подогнан
под историю. Механическая версия сетапа на BTC 2022–2026 устойчивого преимущества не показала.
Решение принимает человек.

Файл: `pine/tw_market_map.pine`. Эталон для сверки: `reference/map.py`.
Другие индикаторы проекта: «TW Спидометр» (`docs/speedometer/README_ru.md`),
«TW Спидометр Pro» и «TW Слепая зона Pro» (`docs/pro/README_ru.md`).

## Установка

1. TradingView → внизу **Pine Editor** → **Открыть → Новый индикатор**.
2. Удалите шаблон и вставьте весь `pine/tw_market_map.pine`. Отступы не меняйте.
3. **Сохранить** → **Добавить на график**. Индикатор встанет на график цены.
4. Добавьте отдельно «TW Спидометр» (`pine/tw_speedometer.pine`) — он рисует скорость
   и ускорение в своей панели. «Карта рынка» их не рисует.

## Связка с «TW Спидометр»

Скорость и ускорение в «Карте» считаются внутри и только для чек-листа, по тем же формулам:
скорость = EMA(5) − EMA(34) от `100 · ln(close)`, ускорение = скорость − EMA(скорости, 5).
Периоды EMA задаются в группе «1. Слепая зона и средние». Если в спидометре стоят те же 5/34/5,
пункты 2, 3, 6 и 7 чек-листа совпадают с тем, что вы видите на его панели.

## Модули

**M1. Слепая зона и средние.** EMA 5 и 34 от логарифма цены (можно обычные) с заливкой: синяя —
быстрая выше, оранжевая — ниже. Прямоугольник «слепая зона» тянется от экстремума режима
до пересечения EMA и рисуется после пересечения. Фон подсвечивает «живую» слепую зону: цена ушла
от экстремума против режима EMA, а пересечения ещё нет. SMA 200 (режим рынка), по желанию
EMA 20 и EMA 50.

**M2. ZigZag.** Два режима:
- пивоты `ta.pivothigh/pivotlow` длины L (по умолчанию 10) — свинг подтверждается через L баров;
- процентный ZigZag — разворот, когда цена ушла от экстремума на заданный процент.

Свинги чередуются: из двух максимумов подряд остаётся больший. Последний незавершённый отрезок
нарисован пунктиром с подписью «не подтверждён — может перерисоваться». Для каждой ноги можно
показать длину в %, длительность в барах и средний объём на бар.

**M3. Ручная разметка.** Выберите тип (импульс / диагональ / зигзаг / плоскость) и введите даты
точек 0–5 или 0-A-B-C. Цена точки — high или low бара по направлению. Нотация степени: ①②③,
(1)(2)(3), 1 2 3 или i ii iii, цвет выбирается. Таблица разметки показывает жёсткие правила (✓ / ✗ / —
с пояснением) и соотношения волн в лог-шкале. Автоматической разметки нет намеренно: надёжной
автоматической разметки волн не существует.

| Тип | Правила |
|---|---|
| Импульс | 2 не за началом 1; 3 не самая короткая из 1, 3, 5; 4 не заходит в зону 1 |
| Диагональ | 4 заходит в зону 1; 2 не за началом 1; 4 не за вершиной 2; форма: сужающаяся 1>3>5 и 2>4 или расширяющаяся 1<3<5 и 2<4 |
| Зигзаг | B не за началом A; C за концом A (иначе «усечение») |
| Плоскость | B ≥ 90 % A; тип: регулярная (B ≤ 105 % A), расширенная (B > 105 % и C за концом A), бегущая (B > 105 % и C не дошёл) |

Соотношения: 3/1, 5/1, 5/3, глубина 2 (от 1), глубина 4 (от 3), B/A, C/A.

**M4. Последний импульс и коррекция A→B→C.** В авто-режиме структура берётся из ZigZag.
- Если последняя нога откатила меньше 100 % предыдущей, A, B и C — три последних свинга
  (коррекция завершена, C подтверждён).
- Иначе A и B — два последних свинга, а C — текущий экстремум коррекции (подписан
  «не подтверждён»).

Направление определяется автоматически. Можно задать A, B и C датами вручную.

Индикатор рисует:
- зоны 38,2 / 50 / 61,8 / 78,6 % (ключевая 50–61,8 % насыщеннее);
- цели волны 3 от C: 1,0 / 1,618 / 2,618 × (B − A) в лог-шкале, по желанию ещё линейные;
- уровни «отмена: начало волны 1 (A)», «конец волны 1 (B)», «стоп идеи (C)» и «первый триггер»
  (последний малый экстремум внутри коррекции).

Подписи стоят справа от последнего бара на подложке и раздвигаются, чтобы не накладываться.

**M5. Каналы** (по ручной разметке импульса или диагонали):
- канал волны 4: линия 2–4 и параллель через 3 — ориентир для волны 5; по желанию параллель
  через 1 (при растянутой 3);
- «норма о каналах»: линия 1–3 и параллель через 2; средняя линия — минимальная цель волны 4,
  удвоенный канал — граница.

**M6. Anchored VWAP** (по hlc3):
- от C — пока C не подтверждён, линия бледная и может переякориться; при переякоривании
  линия прерывается;
- от A — по желанию;
- от даты.

Без объёма модуль отключается с пометкой в таблице.

**M7. Профиль объёма** диапазона: нога A→B, структура A→C или даты. Объём бара делится между
уровнями (40 по умолчанию) пропорционально пересечению high–low с уровнем. Индикатор рисует POC,
VAH и VAL (70 %), а бары профиля — справа от диапазона. Расчёт идёт только на последнем баре
и не больше чем по 1500 барам (настраивается). Без объёма модуль отключается.

**M8. Правило 100–140.** Для ноги A→B или для дат: число баров, статус «мало / норма / много»
и подходящий ТФ ≈ текущий × бары / 120 (в мин / ч / д). Начало волны отмечено вертикальной линией.

**M9. Риск.** Стоп = C ∓ ATR(14) × 0,5. По депозиту и риску на сделку индикатор считает размер
позиции, риск в деньгах и прибыль/риск до каждой цели. Это только расчёт, не рекомендация.

**M10. Чек-лист** — см. ниже. **M11. Оповещения** — см. ниже.

## Как читать чек-лист

| Блок | Пункт | ✓ когда |
|---|---|---|
| ЗОНА | 1 | откат C от волны A→B — в пределах 38,2–78,6 % и не за A |
| | 2 | коррекция медленнее импульса: max\|скорость\| против движения на B→C < K × пик скорости на A→B (K = 0,7) |
| ИСТОЩЕНИЕ | 3 | конвергенция: цена дошла до нового экстремума C, а экстремум скорости коррекции был раньше — на C скорость слабее его хотя бы на 10 % |
| | 4 | средний объём на бар в коррекции ниже, чем в импульсе |
| ТРИГГЕР | 5 | слом структуры: закрытие за «первым триггером» после C |
| | 6 | ускорение по направлению новой волны |
| | 7 | конец слепой зоны: скорость сменила знак по направлению после C (EMA 5/34 пересеклись) |
| | 8 | цена по нужную сторону AVWAP от C |
| ФИЛЬТР | 9 | цена по нужную сторону SMA 200 — только информация, на статус не влияет |

«—» означает «нет данных»: например, нет объёма или нет малого экстремума внутри коррекции.

**Статус:**
- «Зона» — выполнены пункты 1 и 2;
- «Истощение» — «Зона», плюс пункт 3, плюс пункт 4 не ✗;
- «Триггер» — «Истощение» плюс пункт 5;
- «Нет сетапа» — во всех остальных случаях, а также когда коррекция ушла за A («отмена»)
  или цена закрылась за C («стоп идеи»).

Счёт — сколько ✓ из пунктов 1–8. В таблице также стоп, размер позиции, прибыль/риск до целей
и правило 100–140. Метка «Триггер» на графике ставится только на закрытом баре.
Нижняя строка таблицы: «подсказка для анализа, не сигнал к сделке».

## Оповещения

Условия `alertcondition`:
- статус «Зона», «Истощение», «Триггер»;
- пересечение EMA 5/34;
- пробой уровня отмены A;
- пробой первого триггера;
- новый свинг.

Рекомендуемая частота — «Раз за закрытие бара». Вариант «Любой вызов функции alert()» даёт
текст с символом, ТФ, статусом, счётом и уровнями — только на закрытом баре.

## Значения по умолчанию и почему

| Параметр | Значение | Почему |
|---|---|---|
| EMA | 5 / 34, от логарифма | методика; логарифм делает уровни сравнимыми при любой цене |
| ZigZag | пивоты L = 10 | достаточно крупно для волн 100–140 баров; у процентного режима порог зависит от инструмента |
| Малые пивоты | 3 | «первый триггер» — ближайший локальный экстремум |
| Зона, K, конвергенция | 38,2–78,6 %, K = 0,7, 10 % | из постановки задачи, не подбирались |
| Стоп | C ∓ 0,5 × ATR(14) | из постановки задачи |
| Цели | 1,0 / 1,618 / 2,618, лог-шкала | стандартные расширения Фибоначчи |
| Профиль | 40 уровней, VA 70 %, ≤ 1500 баров | стандартная VA; ограничение — ради времени расчёта |

## Как сверить значения с Python

В «Окне данных» TradingView есть строки «Сверка: скорость / ускорение / статус (0–3) / счёт / откат C».
Тот же автомат на Python:

```python
import sys; sys.path.insert(0, "reference")
from speedometer import load_csv
from map import MarketMap, MapSettings
bars = load_csv("data.csv")
recs = MarketMap(bars, MapSettings(zz_len=10)).run()
r = recs[-1]          # последний бар; или recs[i] для нужной свечи
print(r["status"], r["score"], r["items"], r["ret"], r["A"], r["B"], r["C"])
```

Сверяйте свечи дальше 300 баров от начала истории: EMA зависит от затравки на первом баре.
Тесты: `python -m pytest tests reference/tests -q`.

## Ограничения

- Авто-структура A→B→C — эвристика по ZigZag, а не разметка. Она зависит от L или порога
  и перестраивается с каждым новым свингом.
- Свинги в режиме пивотов подтверждаются через L баров, малые пивоты — через 3 бара. Всё, что
  ещё может измениться (последний отрезок ZigZag, неподтверждённый C, AVWAP от него), помечено.
- Каналы строятся в линейной цене. На логарифмическом графике они выглядят иначе.
- Профиль объёма считается по барам текущего ТФ, без внутрибарных данных.
- Исследование вклада пунктов на реальных данных здесь не проведено: среда разработки не имела
  доступа к биржевым данным (см. `research/report.md`). Запустите `research/component_value.py`
  на своём CSV.
- Компилятора TradingView при разработке не было (см. `docs/review.md`). Если компилятор выдаст
  ошибку или предупреждение, пришлите текст и номер строки.
