# TW Спидометр — скорость + ускорение

Индикатор TradingView (Pine Script v6) для **проверки** волновой разметки Эллиотта по скорости цены.
Методика: [tradewaves.ru/teoriya/macd/](https://tradewaves.ru/teoriya/macd/), идеи Б. Вильямса
и pr0 / RSWA. Это не торговая система: индикатор не даёт сигналов «купить/продать» и ничего
не обещает. Он показывает скорость и ускорение движения, а выводы о разметке делаете вы.

Файл индикатора: `pine/tw_speedometer.pine`. Эталон для сверки: `reference/speedometer.py`.
Расширенная версия «TW Спидометр Pro» и «TW Слепая зона Pro» описаны в `docs/pro/README_ru.md`.

## Установка

1. TradingView → внизу **Pine Editor**.
2. **Открыть → Новый индикатор**.
3. Удалите шаблонный код и вставьте весь `pine/tw_speedometer.pine`, от `//@version=6` до конца.
   Не меняйте отступы: в Pine они значимы.
4. **Сохранить** (Ctrl+S) → **Добавить на график**. Индикатор откроется в отдельной панели.

## Что на панели

- **Столбики** — **скорость** = EMA(5) − EMA(34) от `100 · ln(close)`. Значение — в процентах,
  поэтому пики сравнимы при любом уровне цены.
- **Яркость столбика** — **ускорение** по направлению движения. Ускорение = скорость − EMA(скорости, 5),
  то есть гистограмма MACD 5/34/5.
- **Линия ускорения** (розовая) — в выбранном режиме (см. ниже). Подпись у правого края показывает
  масштаб: «ускорение x3».
- **Треугольники** внизу/вверху панели — ускорение сменило знак (ранний сигнал).
- **Ромб «СЗ»** на нуле — скорость сменила знак: EMA 5/34 пересеклись, слепая зона закончилась.
- **Линии дивергенций** с подписями.
- **Таблица состояния**.

## Как читать фазы

| Фаза | Столбик | Смысл |
|---|---|---|
| рост ускоряется | синий, яркий | скорость ≥ 0, ускорение > 0 |
| рост замедляется | синий, бледный | скорость ≥ 0, ускорение ≤ 0 |
| спад ускоряется | оранжевый, яркий | скорость < 0, ускорение < 0 |
| спад замедляется | оранжевый, бледный | скорость < 0, ускорение ≥ 0 |

Цвета взяты из палитры Okabe-Ito, различимой при дальтонизме. Цвет не единственный носитель смысла:
фаза словами есть в таблице, а сигналы различаются формой и подписями.

**Слепая зона** — участок от экстремума цены до пересечения EMA 5/34. Пока пересечения нет, скорость
ещё показывает старый тренд. Фаза «рост замедляется» после пика цены — это и есть слепая зона.
Ромб «СЗ» отмечает её конец.

## Настройки

| 1. Скорость | пресет: Williams 5/34/5, Крупная фигура 13/55/13, Классика 12/26/9, Свои; логарифм; бледность фазы «замедляется» | 5/34/5 и логарифм — по методике; бледность 60 % — различима в обеих темах |
| 2. Ускорение | режим: линия поверх / авто-масштаб / полоса / скрыть; множитель; окно и перцентиль авто-масштаба | линия ×3 — ускорение в несколько раз мельче скорости, ×3 делает форму видимой без подгонки; авто: 500 баров, P95 |

Значения по умолчанию взяты из методики и постановки задачи. Под историю они **не подгонялись**.

### Режимы линии ускорения

- **Линия поверх.** Ускорение × фиксированный множитель (по умолчанию 3). Масштаб одинаков всегда.
- **Авто-масштаб.** Множитель = P95(|скорость|) / P95(|ускорение|) за последние N баров. Он считается
  **один раз**, на последнем баре, и вся линия за N баров рисуется с ним, поэтому масштаб внутри
  истории не «плавает». Значение показано в подписи и в таблице. Пока баров меньше N,
  используется фиксированный множитель с пометкой «мало истории».
- **Полоса у нуля.** Треугольники на нулевой линии: вверх — ускорение > 0, вниз — < 0.
  Насыщенность показывает силу ускорения. Масштаба нет.

## Таблица состояния

- **Фаза** словами (и «ярко/бледно»).
- **Скорость** и **ускорение** со знаком.
- **От пика** — текущая |скорость| в % от максимума |скорости| за окно (по умолчанию 200 баров).
- **Старшие ТФ** (до 3): фаза и скорость. Значение берётся с последней **закрытой** свечи старшего ТФ
  (`lookahead_off`, на истории `[1]`), поэтому не перерисовывается, но запаздывает на одну свечу
  старшего ТФ. Если выбранный ТФ ниже графика, пишется «ТФ ниже графика».
- **Профиль 1-3-5** — если задан режим пиков.
- **Масштаб ускорения** — в авто-режиме.

## Режим «Пики волн 1-3-5»

1. В группе «6. Пики волн 1-3-5» введите даты точек 0…5 изучаемой волны. 0 = не задано.
2. Бар точки — свеча, содержащая эту дату (или первая после разрыва данных).
3. На каждом отрезке индикатор находит экстремум скорости. Для волн 1, 3, 5 он ищется по ходу волны,
   для 2 и 4 — против. Пики подписываются «пик 1», «экстр. 2» и т. д., пики 1-3-5 соединяются линией.
4. Если заданы все шесть точек, профиль классифицируется по правилам:
   - **импульс**: |пик 3| > |пик 1| и |пик 3| > |пик 5|, и волна 4 у нуля: |экстремум 4| < k · |пик 3|;
   - **сужающаяся диагональ (затухание)**: |пик 1| > |пик 3| > |пик 5|;
   - **расширяющаяся диагональ (возрастание)**: |пик 1| < |пик 3| < |пик 5|;
   - иначе — **неопределённо**.

   Пики берутся со знаком направления волны: для нисходящей волны минимум скорости меняет знак.
   **Это профиль скорости, а не разметка**: он говорит лишь, на какой шаблон похожа скорость
   в заданных вами отрезках.
5. Если заданы только точки 0 и 1 (или часть точек), пики рисуются там, где отрезок задан,
   а классификации нет. Если точки не заданы, режим ничего не рисует.

Совет методики: изучаемая волна должна занимать 100–140 баров текущего ТФ. При меньшем числе
спидометр покажет волну старшей степени, при большем — разобьёт её на младшие.

## Оповещения

«Создать оповещение» → индикатор → условие:

- ускорение стало > 0 / < 0;
- скорость стала > 0 / < 0 (конец слепой зоны);
- обычная бычья / медвежья дивергенция;
- скрытая бычья / медвежья дивергенция.

Рекомендуемая частота — «Раз за закрытие бара». Можно выбрать и «Любой вызов функции alert()»:
текст будет с символом, ТФ, фазой, скоростью и ускорением. Такие оповещения срабатывают только
на закрытом баре.

## Дивергенции: честно о запаздывании

Дивергенции ищутся по **скорости**: сравниваются пики волн. Пивот подтверждается только после
«баров справа» закрытых баров (по умолчанию 5), поэтому линия появляется через 5 баров после пика.
Это **не перерисовка** (нарисованное потом не меняется), но и не опережение. Ранний сигнал даёт
ускорение: оно меняет знак раньше, чем скорость.

Цена сравнивается по экстремуму low/high в окне ±2 бара вокруг пивота скорости, а не по close.
Шум отсекается минимальной разницей пивотов (5 % диапазона скорости за 200 баров). Для обычных
дивергенций включён фильтр знака: бычьи — ниже нуля, медвежьи — выше.

## Как сверить значения с Python

1. Получите CSV того же символа и ТФ с колонками `time, open, high, low, close[, volume]`.
   Подойдёт «Экспорт данных графика» TradingView (если есть на вашем тарифе) или выгрузка с биржи.
2. На TradingView откройте **Окно данных** и наведите курсор на свечу. Строки «Сверка: скорость»,
   «Сверка: ускорение» и «Сверка: фаза (1-4)» показывают значения на ней
   (1 — рост ускоряется, 2 — рост замедляется, 3 — спад ускоряется, 4 — спад замедляется).
3. Посчитайте то же в Python:

   ```bash
   python reference/speedometer.py data.csv --at 2024-07-19      # одна свеча (UTC)
   python reference/speedometer.py data.csv --tail 5             # последние 5 свечей
   python reference/speedometer.py data.csv --scale 500          # авто-масштаб ускорения
   python reference/speedometer.py data.csv --divs               # дивергенции
   python reference/speedometer.py data.csv \
       --wave 2024-03-21,2024-04-14,2024-04-28,2024-06-03,2024-06-21,2024-07-19   # пики 1-3-5
   ```

   В выводе: «скорость» = «Сверка: скорость», «ускор.» = «Сверка: ускорение», «фаза» — словами.
4. Сравнивайте свечи **не ближе 300 баров от начала истории**: EMA зависит от затравки на первом баре,
   её вклад затухает, и через 300 баров расхождение пренебрежимо.

Пример на `reference/test_data.csv` (синтетический импульс, 1Д):

```text
время (UTC)              close   скорость      сигн.     ускор.         AO  фаза
2024-07-19 00:00      123.4076     3.6521     3.5031     0.1490     4.2909  рост ускоряется
  профиль 1-3-5 (профиль скорости, не разметка): импульс
```

Тесты: `pip install pytest && python -m pytest tests reference/tests -q`.

## Ограничения

- Индикатор не размечает волны: точки задаёте вы, он проверяет профиль скорости.
- Автоматически классифицируются три профиля: импульс и две диагонали. Треугольники
  (контур сужается или расширяется с обеих сторон нуля) и коррекции (движение медленнее
  предшествующего импульса) читаются глазами.
- Дивергенции запаздывают на «баров справа»; старшие ТФ — на одну свечу старшего ТФ.
- Авто-масштаб рисуется только для последних N баров (до 2000). Левее линии ускорения нет.
- Компилятора TradingView при разработке не было: код проверен ревью, линтером и эталоном
  (см. `docs/review.md`). Если компилятор выдаст ошибку, пришлите её текст и номер строки.
