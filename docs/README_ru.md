# TW Спидометр Pro — инструкция

Набор из двух индикаторов TradingView (Pine Script v6) для **проверки** волновой разметки
Эллиотта через скорость цены. Это не торговая система: индикатор не даёт сигналов
купить/продать и ничего не обещает. Он считает и показывает скорость движения,
а вывод о разметке делаете вы.

| Файл | Что это |
|---|---|
| `pine/tw_speedometer_pro.pine` | «TW Спидометр Pro» — отдельная панель: MACD-спидометр, AO, дивергенции, слепая зона, таблица MTF, анализ волны |
| `pine/tw_blind_zone_pro.pine` | «TW Слепая зона Pro» — на графике цены: EMA 5/34, прямоугольники слепых зон, SMA 200 / EMA 20 / EMA 50, Anchored VWAP |
| `reference/speedometer.py` | Эталонный расчёт на Python для сверки значений |
| `reference/synthetic.py`, `reference/test_data.csv` | Синтетические данные с известными пиками |

Методика: [tradewaves.ru/teoriya/macd/](https://tradewaves.ru/teoriya/macd/), идеи Б. Вильямса
(AO 5/34), исследования pr0 / RSWA.

## Установка

1. Откройте TradingView → внизу **Pine Editor**.
2. **Открыть → Новый индикатор** (или «Создать новый» → «Индикатор»).
3. Удалите шаблонный код и вставьте всё содержимое `pine/tw_speedometer_pro.pine`.
4. **Сохранить** (Ctrl+S), задайте имя.
5. **Добавить на график**. Индикатор откроется в отдельной панели.
6. Повторите для `pine/tw_blind_zone_pro.pine` — он встанет на график цены.

## Что считает спидометр

- **Линия MACD** (столбики) = EMA(5) − EMA(34) от `100 · ln(close)`. Значение — разница средних
  в процентах, поэтому пики сравнимы при любой цене (BTC за 20 000 и за 120 000).
- **Сигнальная** = EMA(5) от линии; **гистограмма** = линия − сигнальная.
- **AO** = SMA(5) − SMA(34) от `100 · ln(hl2)`.
- **Цвет по фазе**: яркий — скорость растёт (столбик дальше от нуля, чем предыдущий),
  бледный — падает. Синий — выше нуля, оранжевый — ниже (палитра Okabe-Ito, различима
  при дальтонизме).

## Настройки (группы)

- **0. Интерфейс** — тема (авто по фону графика / светлая / тёмная), размер текста таблиц.
- **1. Спидометр (ядро)** — пресет периодов: «Williams 5/34/5» (по умолчанию),
  «Крупная фигура 13/55/13», «Классика 12/26/9», «Свои». Логарифм (вкл. по умолчанию).
  Нормировка: «% от логарифма» или «в единицах ATR» (MACD / ATR(14) — для сравнения разных
  инструментов). Периоды AO.
- **2. Отображение** — пресет: всё / только линия / только гистограмма / только AO / свои.
  Чтобы держать линию и гистограмму на разных панелях, добавьте индикатор дважды
  и выберите «Только линия» и «Только гистограмма».
- **3. Старшие таймфреймы** — таблица MTF для трёх ТФ (по умолчанию 1ч / 4ч / 1Д): знак
  и фаза («рост ускоряется / рост замедляется / спад ускоряется / спад замедляется»);
  можно нарисовать линию одного из этих ТФ на панели.
- **4. Дивергенции** — источник (линия / гистограмма / AO), режим (пары пивотов / три пика /
  оба), обычные и скрытые, пивоты (баров слева/справа), мин./макс. расстояние, окно поиска
  экстремума цены, фильтр нуля, минимальная разница, дублирование на графике цены.
- **5. Слепая зона** — боксы (после пересечения), фон (на ходу) или оба.
- **6. Анализ волны** — точки 0–5, порог k для волны 4, подписи точек.
- **7. Объём** — объём в таблице анализа, период SMA для относительного объёма.
- **8. Оповещения** — динамические `alert()`.

### Почему такие значения по умолчанию

- **5/34/5** — периоды методики (AO Вильямса); 13/55/13 и 12/26/9 даны как пресеты, а не подобраны.
- **Логарифм включён** — иначе пики на разных уровнях цены несравнимы.
- **Пивоты 5/5** — достаточно, чтобы на волне 100–140 баров отделить пики волн от шума,
  и задержка сигнала всего 5 баров.
- **Мин. разница 5 % диапазона за 200 баров**, **окно цены ±2 бара**, **k = 0,35** — умеренные
  значения из постановки задачи; они **не подгонялись** под историю.
- **Фильтр нуля включён** для обычных дивергенций (бычьи — ниже нуля, медвежьи — выше).
  На скрытые не действует: они бывают по любую сторону нуля.

## Как читать шаблоны профиля скорости

Сначала проверьте **правило 100–140**: изучаемая волна должна занимать 100–140 баров текущего
ТФ. Если баров меньше — спидометр покажет волну старшей степени, больше — разобьёт её
на младшие. Таблица анализа подскажет, на какой ТФ перейти.

| Шаблон | Как выглядит спидометр |
|---|---|
| **Импульс** | Главный пик — в середине волны 3; в волне 4 спидометр возвращается к нулю; пик волны 5 ниже пика 3 (дивергенция) |
| **Сужающаяся диагональ** | Самый сильный пик — в волне 1, дальше затухание (1 > 3 > 5) |
| **Расширяющаяся диагональ** | Каждый пик выше предыдущего (1 < 3 < 5), дивергенции нет |
| **Сужающийся треугольник** | Контур столбиков сужается с **обеих** сторон нуля |
| **Расширяющийся треугольник** | Контур расширяется с обеих сторон нуля |
| **Коррекция** | Движение заметно медленнее предшествующего импульса |

Треугольники и коррекции индикатор не классифицирует автоматически — их читают глазами
по форме столбиков.

**Слепая зона** — участок от экстремума цены до пересечения EMA 5/34. Пока пересечения нет,
линия MACD ещё показывает старый тренд: пик цены уже прошёл, а спидометр об этом «не знает».
Вывод о смене направления по спидометру можно делать только после окончания слепой зоны.

**Дивергенции** появляются с задержкой «баров справа» (по умолчанию 5): пивот подтверждается
только после 5 закрытых баров. Это не перерисовка (нарисованное потом не меняется),
но и не опережение. Обычные — сплошная линия, скрытые — пунктир, тип подписан текстом.
Режим «Три пика» сравнивает три последних пика (например, волн 1-3-5) и подписывает
«затухание» или «возрастание».

## Таблица анализа волны

1. Включите «6. Анализ волны → Включить анализ волны».
2. Введите время точек 0…5 (дата и время свечи). 0 = точка не задана.
   Если нужны только границы — задайте 0 и 5 или выключите «Использовать точки 1-4»:
   тогда проверяется только правило 100–140.
3. Бар точки — свеча, содержащая введённое время (или первая после разрыва в данных).

Что показывает таблица:

- **Правило 100–140** — число баров между точками 0 и 5 и совет, например:
  «250 баров — много баров…; ≈ ×2.1 → используйте 2ч».
- **По каждой волне**: баров; пик спидометра (для волн 1, 3, 5 — по ходу движения, для 2 и 4 —
  против); средний объём на бар и отношение к волне 3; длина волны в лог-процентах.
- **Профиль скорости**: «импульс», «сужающаяся диагональ», «расширяющаяся диагональ»
  или «неопределённо». Правила:
  - импульс: пик 3 > пик 1 и пик 3 > пик 5, и |экстремум 4| < k · пик 3;
  - сужающаяся: пик 1 > пик 3 > пик 5;
  - расширяющаяся: пик 1 < пик 3 < пик 5.

  Пики берутся со знаком направления волны (для восходящей — максимум, для нисходящей —
  минимум со сменой знака). **Это профиль скорости, а не разметка**: он лишь говорит,
  на какой шаблон похожа скорость в заданных вами отрезках.
- **Лог-соотношения**: 3/1, 5/1, глубина 2 (от 1) и глубина 4 (от 3) — для сверки с Фибоначчи.
- **Объём**: норма для импульса — объём волны 3 больше, чем 1 и 5; относительный объём
  (volume / SMA 20). Если у символа нет объёма, таблица пишет «Объём недоступен
  для этого символа» и не считает этот блок.

## Оповещения

В меню «Создать оповещение» выберите индикатор и одно из условий: обычные/скрытые дивергенции,
три пика, переход через ноль, разворот гистограммы, окончание слепой зоны. Рекомендуемая
частота — «Раз за закрытие бара». Либо выберите «Любой вызов функции alert()»: текст будет
с символом, ТФ и значением спидометра; такие оповещения срабатывают только на закрытой свече.

Окончание слепой зоны совпадает по времени с переходом линии через ноль: это одно и то же
событие (пересечение EMA 5/34), у условий разный текст.

## Как сверить значения с Python

1. Подготовьте CSV с колонками `time, open, high, low, close[, volume]` — например,
   «Экспорт данных графика» в меню графика TradingView (если доступно на вашем тарифе)
   или выгрузку с биржи того же символа и ТФ.
2. На TradingView откройте **Окно данных** (Data Window) и наведите курсор на свечу. Строки
   «Сверка: MACD / сигнальная / гистограмма / AO» показывают значения на этой свече.
3. Посчитайте то же в Python:

   ```bash
   python reference/speedometer.py data.csv --at 2024-07-19
   python reference/speedometer.py data.csv --tail 5          # последние 5 свечей
   python reference/speedometer.py data.csv --atr --preset big --at 2024-07-19
   ```

   Дивергенции, слепые зоны и анализ волны:

   ```bash
   python reference/speedometer.py data.csv --divs --zones \
       --wave 2024-03-21,2024-04-14,2024-04-28,2024-06-03,2024-06-21,2024-07-19
   ```

4. Сравнивайте свечи **не ближе 300 баров от начала истории**: EMA зависит от затравки
   на первом баре, её вклад затухает, и через 300 баров расхождение пренебрежимо.
   Важно, чтобы история в CSV начиналась с того же бара, что на графике, или была
   достаточно длинной.

Пример на `reference/test_data.csv` (синтетический импульс, 1Д):

```text
время (UTC)              close       MACD      сигн.      гист.         AO  фаза
2024-07-19 00:00      123.4076     3.6521     3.5031     0.1490     4.2909  рост ускоряется
bear_reg   пивот 2024-07-19 (пред. 2024-06-03), сигнал на 2024-07-24: осц 10.3438 → 3.6521
Правило 100–140: 120 баров — в норме (100–140)
Направление: вверх; профиль скорости (не разметка): импульс
```

Тесты эталона: `pip install pytest && python -m pytest reference/tests -q`.

## Ограничения

- Индикатор не размечает волны сам: точки задаёте вы, он проверяет скорость.
- Профиль строится по четырём шаблонам; треугольники и коррекции — только визуально.
- Дивергенции видны с задержкой «баров справа»; на незакрытой свече линия может появиться
  и исчезнуть до закрытия бара (оповещения от этого защищены).
- Значения старших ТФ берутся с последней **закрытой** свечи старшего ТФ — без перерисовки,
  но с запаздыванием на одну свечу старшего ТФ.
- «Три пика» сравнивает три последних пивота индикатора; если между пиками волн есть
  мелкие пивоты, увеличьте «баров слева/справа».
- В режиме ATR-нормировки сравнивать абсолютные значения разных инструментов можно,
  но зависимость от волатильности периода остаётся.
- Компилятора TradingView при разработке не было: код проверен ревью и линтером
  (см. `docs/review.md`). Если компилятор выдаст ошибку — пришлите её текст.
